Problem Solving

How I break down bugs and challenges.

My Process

  1. 1

    Understand

    Reproduce the problem and read the error message carefully.

  2. 2

    Plan

    Break it into small steps and form a theory about the cause.

  3. 3

    Build

    Change one thing at a time and test after each change.

  4. 4

    Review

    Confirm the fix, clean up and write down what I learned.

Case Studies

Mobile menu not opening

Problem The hamburger button did nothing on phones.

Approach Checked the Console, then confirmed the script was loading and the element IDs matched.

Result Fixed the file path and IDs. The menu now opens and closes reliably.

Horizontal scrolling on mobile

Problem The page was wider than the screen at 375 px.

Approach Used DevTools to find the element that overflowed and tested at several widths.

Result Switched to flexible widths and wrapping, so nothing overflows.

Form errors were unclear

Problem Visitors could not tell which field was wrong.

Approach Added per-field messages, colour cues and moved focus to the first error.

Result Clear, accessible feedback on every field.
