Assemble Desktop Computer

Overview

A hands-on hardware project: assembling and testing a desktop computer, from opened cases and loose parts to a working Windows desktop.

  • Hardware assembly
  • Troubleshooting
  • BIOS setup

What the photos show

  • Computer cases opened on a work table, with a motherboard and processor cooler installed in them
  • Power supply units, hard drives, cables, screwdrivers and work gloves laid out beside the cases
  • A monitor and keyboard connected for testing
  • The startup screen, the BIOS setup menu, and finally a Windows desktop on the monitor

My contribution

I assembled the desktop computer. I put the parts together, connected the monitor and keyboard, and tested it until it reached the BIOS setup screen and a Windows desktop.

Assembly steps

  1. Prepare the tools and lay out the parts: case, motherboard, processor, memory, power supply and drives.
  2. Install the processor, cooler and memory on the motherboard.
  3. Fit the motherboard in the case and connect the power supply and drives.
  4. Connect the monitor and keyboard.
  5. Power on and check the startup screen for the detected processor, memory and hard disk.
  6. Open the BIOS setup menu and check the settings.
  7. Start Windows and confirm the desktop loads.

Problem noticed

The startup screen reported a warning for the Hitachi hard disk: S.M.A.R.T. Status BAD, Backup and Replace. This means the drive may be failing, so it should be backed up and replaced.
