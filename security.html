Web Security

Good habits that keep sites and people safe.

Practices I Follow

Safe coding habits

  • Validate input on the client and on the server
  • Never put passwords or API keys in a public repository
  • Use rel="noopener noreferrer" on external links
  • Serve sites over HTTPS
  • Keep tools and dependencies up to date

Personal security

  • Unique, strong passwords with a password manager
  • Two-factor authentication on GitHub and email
  • Think before clicking links or downloading files
  • Back up important work
  • Review app permissions regularly

Honest note about this website
